Project Case Studies

~/genai · multi-agent

HealthLink — AI Health Triage

View code
The Problem

People describing symptoms in plain words don't know which specialist they need or how urgent it is — and a single LLM call returns shallow, unstructured answers.

The Approach

A 4-agent pipeline orchestrated end-to-end: symptom extraction (RAG-enriched from a medical KB), specialist matching, appointment scheduling, and a plain-language summary — built on FastAPI with Claude structured outputs, Pinecone + local Sentence-Transformer embeddings.

The Result

A full-stack app deployed on Cloud Run with GitHub Actions CI/CD — two containerized services, React & Streamlit frontends, secrets in Secret Manager, and graceful degradation when RAG is disabled.

~/genai · text-to-sql

Zomato NL→SQL Engine

View code
The Problem

Non-technical users couldn't query a Zomato-style orders database without knowing SQL. Every question meant waiting on someone who could write the query.

The Approach

Built a FastAPI backend that feeds the live DB schema as context to an LLM, generates SQL, executes it against SQLite, and returns clean JSON — over 5,000 synthetic records.

The Result

Plain-English questions answered instantly — covering aggregations, time-based, and multi-condition queries, all backed by integration tests so the generated SQL stays trustworthy.

~/genai · retrieval

RAG PDF Question-Answering

View code
The Problem

Answers locked inside long PDFs are hard to find. People needed to ask questions of a document instead of scrolling through it.

The Approach

An end-to-end RAG pipeline: ingest PDFs, chunk with RecursiveCharacterTextSplitter, embed locally with Sentence Transformers, and persist vectors in Chroma DB. Used MMR retrieval for diverse, relevant context.

The Result

A working QA app with MD5 deduplication to avoid re-indexing, and swappable LLM/embedding providers (Anthropic/OpenAI, local/API) via simple .env config.
